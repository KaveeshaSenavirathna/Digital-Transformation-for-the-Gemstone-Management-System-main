## 📖 Introduction
The **Digital Gemstone Management System (DGMS)** is a comprehensive web-based platform designed to revolutionize Sri Lanka's traditional gemstone industry. This integrated system addresses critical challenges in gemstone traceability, certification, inventory management, and global market access for small to medium-scale enterprises.

Built with modern technologies and user-centered design principles, DGMS serves as a centralized digital hub connecting all stakeholders in the gemstone supply chain - from miners and certifiers to traders and international buyers.

---

## 🎯 Project Vision
To bridge the technological gap in Sri Lanka's gemstone industry by providing an affordable, scalable, and user-friendly digital platform that enhances transparency, efficiency, and global competitiveness while preserving the industry's rich heritage.

---

## ✨ Key Features

### 🔍 Core Modules
| Module | Description |
|--------|-------------|
| **Production Management** | End-to-end gemstone processing from raw intake to final grading |
| **Inventory Management** | Real-time stock tracking with QR code integration and automated alerts |
| **Employee Management** | Role-based task allocation and performance monitoring |
| **Certification System** | Digital certificates with QR verification and authentication |
| **Digital Marketplace** | E-commerce platform with live auction capabilities |
| **Financial Management** | Automated accounting, payroll, and compliance reporting |
| **Analytics Dashboard** | Real-time insights and customizable reports |

### 🛡️ Security Features
- 🔐 Role-Based Access Control (RBAC)
- 🔒 JWT/OAuth 2.0 Authentication
- 🛡️ HTTPS/SSL Encryption
- 📊 Comprehensive Audit Trails
- 🚨 Real-time Security Monitoring

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- MongoDB Atlas account or local installation
- Git for version control

### Installation
```bash
# Clone the repository
git clone https://github.com/KaveeshaSenavirathna/Digital-Transformation-for-the-Gemstone-Management-System-main.git

# Navigate to project directory
cd digital-gemstone-management-system

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env

# Start development server
npm run dev
```
